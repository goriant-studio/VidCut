Architecture

Pure Rust Workspace

3 focused crates — clear separation of concerns with zero C++ dependencies.

🖥️
vidcut-app
Binary crate. UI entry point via eframe. All panels: Toolbar, Media Browser, Inspector, Preview, Timeline.
Binary egui eframe
⚙️
vidcut-core
Library crate. Project model, Timeline, Track, Clip, MediaAsset, Command pattern with full Undo/Redo history.
Library serde Commands
🎬
vidcut-media
Library crate. FFmpeg wrappers, media probing, thumbnail generation, frame cache (LRU), audio decode.
Library FFmpeg wgpu
